# Telegram ChatGPT Bot

This repository contains the source code for a Telegram bot that utilizes ChatGPT's capabilities. The bot allows users to interact with the AI model, ask questions, and receive real-time responses.

## Features
- Interactive communication with ChatGPT via Telegram.
- Supports various types of queries and tasks.
- Easy integration with external services and APIs.
- Simple setup and configuration process.

## Requirements
- Python 3.x
- `g4f and aiogram` library
